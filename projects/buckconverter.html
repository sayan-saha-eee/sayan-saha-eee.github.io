Programmable Synchronous Buck Converter

Description

I designed a synchronous buck converter using the IR2104 half-bridge driver and IRLB8743 MOSFETs. The converter can be controlled by any microcontroller using PWM. Peak efficiency reached approximately 92% in continuous conduction mode (tested at 12V input, 7V / 2A output using an ESP32 at 19kHz, 12-bit PWM).

Technical Details

A synchronous buck converter replaces the traditional freewheeling diode with a low-side MOSFET, significantly reducing conduction losses and improving high-current efficiency.

Operation & Limitations: Proper gate driving and dead-time control are critical to avoid shoot-through short circuits. The IR2104 handles this with a fixed 500ns dead time. While functioning as expected, the fixed dead-time and complementary switching limit control flexibility. Additionally, reverse current backflow occurs when output voltage exceeds input voltage—a known topology limitation.

Key Components

  • IR2104 - Half-Bridge Gate Driver
  • IRLB8743 - N-Channel MOSFETs (High-side and Low-side)
  • Inductor & Capacitor - LC Output Filter
  • Bootstrap Diode & Capacitor - For high-side MOSFET driving
  • ESP32 - Microcontroller (used for PWM testing)
