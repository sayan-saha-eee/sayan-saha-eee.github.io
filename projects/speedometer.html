Smart Speedometer

Introduction

Traditional bicycle speedometers typically display only speed and distance, lacking comprehensive health, safety monitoring, or data logging. Professional multi-sensor units exist but are often prohibitively expensive. To address this gap, this project focuses on designing an affordable cycling speedometer. The system is built around an ESP32 and integrates real-time telemetry, rear-proximity vehicle alerts, and an automatic emergency SOS system.

Version 1: Smart Telemetry & Proximity

The initial version of the project focused on basic ride telemetry and rider safety.

  • Telemetry Data: An A3144 Hall Effect sensor calculates instantaneous speed and distance via wheel rotation. A DHT11 sensor tracks ambient temperature and humidity. An MPU6050 IMU measures the path's inclination.

  • Rear Proximity Alert: A VL53L0X LiDAR sensor is used to measure the distance of objects behind the bicycle. It triggers a display alert if a vehicle approaches within 2 meters. This is helpful since the rider doesn't need to look back.

  • Bluetooth Logging: Ride parameters are displayed on a 0.96" OLED screen and transmitted to a smartphone over Bluetooth. The "START" and "STOP" commands in the Bluetooth app is used to control the device. After the ride, a post-ride data summary is sent to the mobile device.

Version 2: Emergency SOS System

In the second iteration, I added an automatic emergency SOS system that operates independently of a smartphone.

  • Crash & Fall Detection: : The MPU6050 accelerometer and gyroscope monitor for sudden impacts or unusual tilt angles. Impacts are detected if there is high acceleration. Falls are detected if the tilt angle exceeds 60°.

  • SOS Dispatch: When a crash is detected, the system immediately attempts to lock onto GPS coordinates for up to 5 seconds using a NEO-6M module. It then uses a SIM800L GSM module to send an automated SMS-containing a Google Maps location link-to a pre-configured emergency contact. The system locks the display with a crash warning until the bicycle is physically returned to an upright position (less than 30 degrees).

Components

  • ESP32: Microcontroller
  • A3144: Hall Effect Sensor
  • DHT11: Temperature and Humidity Sensor
  • MPU6050: IMU (Accelerometer & Gyroscope)
  • VL53L0X: Time-of-Flight LiDAR Sensor
  • SIM800L: GSM Module
  • NEO-6M: GPS Module
  • OLED: 0.96-inch I2C Display
